# Accueil AutoPay

**Route :** `pages/index/index`

Le tableau de bord présente le budget mensuel estimé à partir des bénéficiaires actifs, les prochaines échéances et les paiements nécessitant une vérification. Les actions principales ouvrent les pages Bénéficiaires, Programmer, Calendrier et Historique.

Les valeurs viennent du jeu de données fictives partagé dans `utils/autopay/store.js`. Le badge de démonstration rappelle qu'aucun transfert réel n'est exécuté.
